# Research-Space

A personal website template for a **Research & Insight Senior Manager** with a background in:

- Learning & Development (L&D)
- User Research
- Organizational Effectiveness

## Purpose

This site is designed to be your digital footprint and personal brand space where you can:

- Publish writing and thought leadership
- Share practical insights
- Showcase selected projects and outcomes
- Provide an easy way for people to connect with you

## Run locally

Open `index.html` directly in your browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
